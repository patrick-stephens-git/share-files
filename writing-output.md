# Writing Output Skill
 
Before finalizing any written text output, scan it against the patterns below. If a pattern appears, rewrite that line using the fix. Do this as a final pass after drafting, not while drafting.
 
---
 
## Avoid AI Tells
 
- **Em dashes**
  Example: "We shipped the update last night — users are already reporting fewer crashes."
  Fix: Rewrite as two sentences, or use a comma, colon, or parentheses instead.
- **"That's not X. That's Y." construction**
  Example: "That's not compliance. That's stalling."
  Fix: Cut the setup. Keep only the second half. → "That's stalling."
- **"That's X, that's not Y." construction**
  Example: "Build a metrics funnel, not one number."
  Fix: Cut the setup. Keep only the first half. → "Build a metrics funnel."
- **Two short fragments stapled together for rhythm**
  Example: "Fast. Simple." / "No fluff. Just answers."
  Fix: Pick one. Write it like a person would say it out loud.
- **Abstract metaphor pairs with no concrete instruction**
  Example: "Less a hammer, more a scalpel."
  Fix: Drop the imagery. State plainly what to do instead.
- **Self-congratulating tags**
  Example: "And that matters." "That's the part everyone misses." "Which is exactly the point."
  Fix: Delete the sentence entirely. Nothing is lost.
- **Unexplained analogy that assumes shared context**
  Example: "It's the Excel of AI agents."
  Fix: Only use an analogy if both sides of it are things the reader can be expected to know. Otherwise, describe the thing directly.
- **Throat-clearing before the actual point**
  Example: "Here's the thing." "Let me be clear." "The truth is."
  Fix: Delete the lead-in. Start with the sentence that comes after it.
- **Forced rule-of-three**
  Example: "Faster, cheaper, smarter."
  Fix: Use however many reasons are actually true — one, two, five. Never default to three for the sake of rhythm.
- **Vague ranges standing in for a real number**
  Example: "5 to 10 minutes."
  Fix: Commit to one number. "7 minutes."
- **Summary that restates the whole piece**
  Example: "In short…" "At the end of the day…"
  Fix: Delete it. End on the last real point, not a recap.
## How to apply this
 
- Draft normally.
- Re-read the draft once, checking only for these patterns.
- Fix each match using the corresponding rule.
- Don't over-correct into choppy, staccato text. The goal is to sound like a person wrote it, not to hit a word count or avoid all structure.
